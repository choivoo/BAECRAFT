# 화면 명세 (모바일 기준, 공식 소개문의 일반적 구성 참고)

- 하단 탭 5개: 홈 / 검색 / 주문내역 / 찜 / 마이 (아이콘은 자체 이모지·SVG)
- 상단 바: 배달 주소(탭하면 변경), 장바구니 버튼(개수 배지)
- 홈: 카테고리 칩(가로 스크롤), 가게 카드 목록(이모지 썸네일, 평점, 배달시간, 배달비, 최소주문), 정렬 선택
- 검색: 입력창(한글 IME 안전), 결과 목록
- 가게 상세: 헤더(찜 하트), 메뉴 목록 + 담기 버튼, 하단 고정 "장바구니 보기" 바
- 장바구니: 라인별 +/−/삭제, 금액 요약(상품/배달비/합계), 요청사항, 주소, "주문하기"
- 주문내역: 진행 중/지난 주문, 상세(상태 진행바), 취소·재주문·리뷰
- 마이: 주소, 파일 열기/저장(JSON), CSV 내보내기, 되돌리기/다시실행 버튼, 초기화
- 단축키(데스크톱 보조): Ctrl+Z 되돌리기, Ctrl+Y/Ctrl+Shift+Z 다시실행, Esc 뒤로, Ctrl+K 장바구니, Ctrl+1~5 탭
- 모든 버튼·단축키는 `run(commandId)` 하나로만 상태를 바꾼다 (`src/core/commands.ts`).
