# 아직 안 되는 것 (GAPS)
- 실제 서버·지도·실시간 라이더 위치·카드/간편결제: 없음 (주문은 기기 안에서만 기록, 배달 단계는 '다음 단계로(데모)' 버튼으로 진행)
- 메뉴 옵션(맵기·토핑 등), 쿠폰/포인트, 가게 사진: 미구현 (이모지로 대체)
- 주문 상태 진행바는 단계 표시만 하고 현재 단계 강조가 약함
- 실제 폰 설치용 PWA(오프라인 캐시·홈 화면 아이콘), 모바일 실기기 확인: 미수행 (Chromium 360px 에뮬레이션으로만 확인)
- Windows/Mac 데스크톱 앱(Electron) 포장: 모바일 기준 요청에 따라 제외. 단일 HTML 을 브라우저로 열면 됨
- 한글 IME 는 자동 테스트로 문자열 유지만 확인, 실제 조합 입력은 실기기 확인 필요
