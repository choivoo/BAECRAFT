# 한끼콕 기능 명세 (SPEC)

근거(클린룸): 원본 앱의 공개 앱스토어 소개문에 나온 기능 설명만 사용. 원본 코드·이미지·이름·폰트 미사용.
원본은 공개된 파일 형식 규격이 없는 서비스형 앱이므로, 공개 대체 형식으로 **JSON(`hankkikok/1`)** 과 **CSV(주문내역)** 를 사용한다.
범위: 사람들이 가장 많이 쓰는 핵심 흐름 = 가게 찾기 → 메뉴 담기 → 주문 → 배달 현황 → 리뷰, 찜, 재주문.

| ID | 기능 | 명령 | 완료 기준 (한 줄) |
|----|------|------|------|
| F1 | 가게 목록·카테고리 | search.category | 카테고리를 고르면 해당 카테고리 가게만 보인다 |
| F2 | 검색 | search.query | 가게명 또는 메뉴명 일부로 검색하면 일치하는 가게만 나온다 |
| F3 | 정렬 | search.sort | 평점/도착시간/배달비 순으로 정렬된다 |
| F4 | 가게 상세 | store.open | 가게를 열면 메뉴·최소주문·배달비가 보이고 뒤로가기로 돌아온다 |
| F5 | 장바구니 담기/수량 | cart.add/inc/dec/remove/clear | 담기·증감·삭제가 합계에 즉시 반영되고 0개면 삭제된다 |
| F6 | 한 가게 규칙 | cart.add | 다른 가게 메뉴를 담으면 기존 장바구니가 새 가게로 교체된다 |
| F7 | 주문하기 | order.place | 최소주문금액 이상일 때만 주문되고 접수 상태 주문이 생긴다 |
| F8 | 배달 현황 | order.advance | 주문 상태가 접수→조리중→배달중→완료로 진행된다 |
| F9 | 주문 취소 | order.cancel | 접수 상태에서만 취소된다 |
| F10 | 재주문 | order.reorder | 지난 주문의 메뉴가 그대로 장바구니에 담긴다 |
| F11 | 리뷰 | review.submit | 완료된 주문에만 별점·글을 남길 수 있다 |
| F12 | 찜 | store.favorite | 찜을 켜고 끌 수 있고 찜 탭에 모인다 |
| F13 | 배달 주소·요청사항 | address.set / request.set | 입력(한글 포함)이 주문에 기록된다 |
| F14 | 되돌리기/다시실행 | edit.undo/redo | 모든 데이터 변경(F5~F13)을 Ctrl+Z / Ctrl+Y 로 되돌린다 |
| F15 | 파일 열기/저장 | data.import/exportJson | 열기→저장→다시열기 시 내용이 바뀌지 않고 모르는 필드도 보존된다 |
| F16 | 주문내역 CSV | data.exportCsv | 주문이 CSV(한글 BOM)로 내보내진다 |
| F17 | 모바일 화면 | — | 360px 폭에서 가로 스크롤 없이 하단 탭으로 사용된다 |
